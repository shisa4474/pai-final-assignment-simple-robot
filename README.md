# PAI Final Assignment - simple_robot

This repository contains the SDF model and world files used in the PAI Final Assignment.

The robot (a simple box model) was moved manually in Ignition Gazebo using the GUI "Apply Force" tool.
A 1 minute 30 second video was recorded showing the robot performing the assigned task.

AI (Microsoft Copilot) was used for:
- Debugging SDF errors
- Fixing model loading issues
- Guidance on Gazebo operation
- Assistance in preparing the final report and submission materials
